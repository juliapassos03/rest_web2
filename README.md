O banco MySQL deve estar rodando com:
- **Usuário:** root
- **Senha:** root
- **Porta:** 3306

Configurar o Java no VS Code

Abra o arquivo `.vscode/settings.json` e altere os caminhos do JDK para o da sua máquina:

```json
"java.jdt.ls.java.home": "C:\\Program Files\\Java\\jdk-21",
"spring-boot.ls.java.home": "C:\\Program Files\\Java\\jdk-21"
```
